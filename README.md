# Productivity Manager – Frontend

React + TypeScript frontend for a productivity management web application.

# Product description

Built on top of Supabase for authentication and data storage, this app enables users to manage tasks, projects, courses, deadlines, and focused work sessions through a clean, component-driven UI.

Designed as a learning project, with emphasis on modern frontend architecture, authentication flows, and scalable UI patterns.

# Tech stack:

React, TypeScript, Supabase Auth, PostgreSQL, Netlify

# Testing

- To run tests I used Vitest, @testing-library/react, jsdom .
- To install dev dependecies for testing, run:  
   npm install -D vitest @testing-library/react @testing-library/jest-dom jsdom
- Helps: in the console press:
  a: rerun tests
  r: retrun tests suite (same as a)
  q: quit testing session
